# 演奏教材JSONの作り方

「表示・速さ・音の設定」→「教材JSONを開く」でUTF-8のJSONファイルを選びます。ファイルは端末内で読み、アップロードしません。JSONにはコメントや末尾のカンマを書けません。無料教材の完全例はsamples/にあります。

## 最小の例

```json
{
  "schemaVersion": 1,
  "id": "my-rhythm",
  "revision": "1",
  "title": "FとJのリズム",
  "countInBeats": 4,
  "sound": {"preset":"chip", "default":"miss", "keys":{"f":60,"j":67,"space":48}},
  "events": [
    {"e":"tempo","beat":0,"bpm":80},
    {"e":"barline","beat":0,"style":0},
    {"e":"hint","beat":0,"text":"F と J でリズムをつくろう"},
    {"e":"note","beat":0,"key":"f"},
    {"e":"note","beat":1,"key":"j"},
    {"e":"note","beat":2,"key":"space"},
    {"e":"barline","beat":4,"style":0}
  ]
}
```

idは教材の識別名、revisionは内容の版、titleは画面に出す名前です。内容を更新したらrevisionも変えます。soundは省略できます。

## 拍と区切り

1 beatは拍線・メトロノーム1個分です。四分音符などの音符名には固定しません。BPM80なら毎分80クリック。beatは曲頭0からの絶対位置で、0.5などの途中も指定できます。クリックは整数拍で鳴ります。

| e | 項目 | 意味 |
|---|---|---|
| tempo | beat,bpm | その拍から一定BPM。beat0に1つ必須 |
| tempoRamp | beat,toBeat,toBpm | 拍の位置に対して直線に加速・減速。開始BPMは直前から引継ぐ |
| note | beat,key | 流れてくる入力のお手本 |
| hint | beat,text | ヒント帯の文章。次のhintまで維持し、空文字で消す |
| barline | beat,style | 好きな位置の区切り線。0は太い実線、1は破線 |

6個ごとに区切るなら、beat0と6にstyle0、途中の3にstyle1などと書けます。次が5個でも構いません。拍子記号やmeterイベントは使いません。tempoRampの重複や途中へのtempo挿入はできませんが、終点から次のテンポ制御を置けます。

countInBeatsは曲頭前の予備拍数（0以上の整数）。6拍の区切り2回分なら12です。アウフタクトは最初のnoteを0、次の大きい区切りを1などと指定します。予備拍中の速さは曲頭BPMを使います。

## ヒントにルビを付ける

`text` の中へ半角の `|親文字{よみ}` と書きます。たとえば次のヒントは「朝」の上に「あさ」、「一緒」の上に「いっしょ」と表示します。

```json
{"e":"hint","beat":0,"text":"|朝{あさ}だ、|一緒{いっしょ}に"}
```

無料教材「ことば『朝だ』」の最初のヒントでも表示を確認できます。

ルビは何か所でも指定できます。親文字とよみはどちらも1文字以上にし、その中に `|`・`{`・`}` や改行を入れません。縦線は半角 `|` を使ってください。全角 `｜` は普通の文字として表示します。`|朝{}` や閉じ括弧のない記法は、そのまま文字として残ります。ルビを書かない文章も従来通り表示できます。

ヒント帯は短い1行を目安に作ります。改行する場合はJSONの文字列に `\n` を書きます。長いヒントや複数行は帯の中を手動で縦にスクロールできますが、演奏しながら読みやすい長さにしてください。ルビ記法を含めて2000文字までです。HTMLタグは文章として表示され、装飾や画像の挿入には使えません。
## キーと指

keyは小文字a〜z、半角の`,`、半角の`.`、`space`の29種類です。画面では`,`を「、」、`.`を「。」と表示します。JSONに日本語の句読点や空白1文字を直接書かず、正規のkeyを使ってください。

一般的な日本語キーボードのComma（ね／、）とPeriod（る／。）をIME OFFで押します。日本語変換で入力する機能ではありません。Shift/CapsLockによる英字の大小は問いません。

10レーンの並びはQAZ / WSX / EDC / RFV / TGB / YHN / UJM / IK, / OL. / Pです。F/Jが人差し指の基本位置、TGB/YHNは同じ人差し指を内側へ伸ばす列です。「、」は右中指、「。」は右薬指。Spaceは左右どちらかの親指で押し、中央の横長ノートで示します。両親指の同時押しは必要ありません。

同時ノートや長押しノートは作れません。同じキーを続けるときも一度離して押します。Spaceと英字を交互に置くときは、手を動かす余裕を持たせてください。読む時間が必要なhintはnoteより早く出せます。ノート同士が重ならない程度の間隔を取り、お手本と実際の操作で確かめます。

## 音を決める

1曲につき音セットは1つ。`chip`は短いピコピコ音で、キーごとにMIDI番号36〜96の整数（69=440Hz）か`"miss"`を指定します。MIDI機器は要りません。`"default":"miss"`にしてF/Jだけ音高を指定すると、他のキーは短いハズレ風の音になります。音の割当は押したキーで決まり、タイミングでは変わりません。

`drums`は打楽器風の短い音セットです。keysの値には次のID、または`"miss"`を指定します。

- kick-1〜kick-6：太鼓風
- tom-1〜tom-6：タム風
- wood-1〜wood-6：木を打つ音風
- snare-1〜snare-6：スネア風
- hat-1〜hat-5：ハット風

同じ種類では数字が大きいほど高い音になります。例：`"sound":{"preset":"drums","default":"miss","keys":{"f":"kick-1","j":"snare-1"}}`。楽器録音の再現ではなく短い合成音です。

sound省略時はchip。キーボード順QWERTYUIOP/ASDFGHJKL/ZXCVBNM/`,`/`.`/spaceへMIDI48〜76を割り当てます。drums標準は同じ順にkick-1,tom-1,wood-1,snare-1,hat-1,kick-2…snare-6です。default省略なら各キーの標準音、keysを指定すればそれが優先します。

遊ぶ人は設定内のキーボード配置の表で音を変えられます。「教材の設定に戻す」で復元。再演奏では変更を保ち、教材切替で新しい教材の設定へ戻ります。変更はブラウザ終了後の保存をしません。

## 読込チェック

最大5MB、イベント1〜100,000個（noteを少なくとも1個）、BPM20〜400、beatは0以上の有限数です。noteは同拍に1つまで。未知のイベントは警告して読み飛ばすので、必須の音や操作を未知のイベントだけに書かないでください。未知の音セット・打楽器IDは警告して標準へ戻ります。不正な型や範囲外の音高はエラーです。noteに使うキーがmissのままなら警告します。
