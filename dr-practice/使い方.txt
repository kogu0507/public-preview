ドラム練習

操作
1. index.html をChromeやEdgeなどで開きます。通信・インストールは不要です。
2. 音量を小さくして「再生」を押します。1小節を繰り返します。
3. 図形譜とドラムの点灯を参考に、パッドまたは表示されたキーで演奏します。
4. 「停止」で止めます。次の再生は小節の最初からです。

・テンポは40～160 BPM、初期60。BPMは四分音符の速さです。
・手本の音とメトロノームは個別にON/OFFできます。手本音OFFでも入力で発音します。
・色と小さな●は手本の短い点灯、濃い枠は自分の入力です。採点はしません。
・「実機配置」はハイハット左、「スマホ配置」はハイハット右です。
・右手/左手/右足などの担当は教材の情報で、配置切替では反転しません。
・既定キーは 1=バス、2=スネア、3=ハイハット。停止中も演奏できます。
・設定欄の編集中、数字/文字キーは演奏に使いません。
・画面の切替や音の中断で停止します。戻ってから再生してください。
・短い点灯は最大100ms。極端に細かい教材では端末の表示速度に限界があります。

教材を整える方へ
先生や見守る方が、利用者に合う担当、読み、メモ、リズムを設定できます。
「教材設定」のJSONを編集・貼り付け、「反映」を押してください。
正常なら停止して描画し、不正な場合は元の教材を保ちます。
JSONや設定は保存しません。編集した教材は別途保管してください。
担当は本人や教室の指導に合わせて変更してください。

JSON例（元の基本教材）
{
  "name": "教室の基本リズム",
  "meter": [4, 4],
  "subdivisions": 4,
  "instruments": [
    {"id":"hh","label":"ハイハット","key":"3","limb":[{"text":"右手","ruby":"みぎて"}],"sound":"hihat"},
    {"id":"sn","label":"スネア","key":"2","limb":[{"text":"左手","ruby":"ひだりて"}],"sound":"snare"},
    {"id":"bd","label":"バス","key":"1","limb":[{"text":"右足","ruby":"みぎあし"}],"sound":"bass"}
  ],
  "notes": [
    ["bd","hh"], [], ["hh"], [],
    ["sn","hh"], [], ["hh"], ["bd"],
    ["bd","hh"], [], ["hh"], ["bd"],
    ["sn","hh"], [], ["hh"], []
  ]
}

項目
・name：教材名。1～60文字。
・meter：[分子,分母]。分子1～12、分母2/4/8/16。
・subdivisions：このアプリの1拍をいくつに分割するか。1～8。
・instruments：楽器の配列、1～8楽器。配列の順番が図形譜の行順です。
  id：楽器の識別名。半角小文字・数字・_・-、1～24文字。重複不可。
  label：楽器名。1～32文字。
  key：半角小文字または数字1文字。重複不可。例 "a", "4"。
  limb：演奏担当の表記。1～24文字。例 "右手", "左足", "両手"。
  sound：bass / snare / hihat / crash / tom のいずれか。
  ID・名前・担当・キーは音色と別です。タムやクラッシュも楽器定義を追加して使えます。
・notes：1小節の全位置。配列の数は 分子×subdivisions、最大64。
  各位置に楽器idを並べます。[]は打点なし、["bd","hh"]は同時打ち。
  未定義id、同じ位置の重複idは不可です。
・memos（任意）：notesと同じ長さの文字列配列。各位置24文字まで。空文字可。
  例：["ド", "", "カ", "", "tu", "", ...]（実際のJSONでは省略記号を使わず全位置を書く）
  メモがある教材や位置数が多い教材は、図形譜の中を横にスクロールできます。
・beatLabels（任意）：分子と同じ個数の拍名。例 ["1", "2", "3", "4"]。
  表示名だけを変え、クリック数や時間は変えません。
・記載以外の項目はエラーになります。JSON全体32,768文字以内。

拍とBPM
このアプリではmeter=[n,d]の1拍は「分母dの音符1個」です。
1拍をsubdivisions等分し、メトロノームは分母音符ごとにクリックします。
BPMの基準は常に四分音符です。分母が8でもBPMの基準は変えません。
1位置の秒数 = 60 / BPM × 4 / d / subdivisions
1小節の秒数 = 60 / BPM × 4 / d × n
例：3/4・subdivisions=2なら6位置。120 BPMで1小節1.5秒、四分音符3クリック。
例：6/8・subdivisions=2なら12位置。120 BPMで1小節1.5秒、八分音符6クリック。
6/8の大きな2拍（付点四分音符）を自動解釈する機能ではありません。

ルビ
name、label、limb、beatLabelsの各拍名に同じ形式を使えます。
普通の文字列ならそのまま表示します。
読みを付ける場合は、文字列と{text,ruby}だけの配列にします。
例 "label": [{"text":"低音","ruby":"ていおん"}, "タム"]
例 "beatLabels": [[{"text":"一","ruby":"いち"}], "2", "3"]
1フィールド20部分まで、表示文字数は各項目の上限内、各rubyはその上限の2倍以内。
HTMLは入力できません。<b>なども装飾せず文字として表示します。
memosは普通の文字列だけです。ド、カ、tuなど、そのまま読みやすく書けます。

旧形式
{"name":"教材名","notes":[...16個の配列...]} も取り込めます。
この場合だけ1=バス、2=スネア、3=ハイハットの数字を使います。
4/4・1拍4分割として変換します。旧keyMap、任意長、クラッシュ4には対応しません。

端末について
スマホのローカルHTMLの開き方や音の出方は端末で異なります。
音が出ないときは端末音量を確認し、再生やパッドをもう一度操作してください。
音色は簡単な合成音です。実際の手足や楽器の使い方は教室などの指導に合わせてください。
